# VANGUARD PROTOCOL // Tactical FPS

Landing page resmi bertema game tactical shooter 5v5 yang dibangun menggunakan HTML5 dan Tailwind CSS.

## Fitur Utama
- Desain antarmuka taktis bertema gelap (Dark Tactical UI).
- Informasi kelas agen (*Duelist*, *Recon*, *Sentinel*).
- Tampilan responsif untuk desktop maupun perangkat mobile.

## Teknologi yang Digunakan
- HTML5
- Tailwind CSS (CDN)
- Google Fonts (Orbitron & Rajdhani)
